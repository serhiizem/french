# 04 · Les pronoms y et en

> **Tu veux du fromage ? — Oui, j'en veux.** · **Tu vas au marché ? — Oui, j'y vais.**
> **en** replaces **de** + something. **y** replaces **à** + something, or a place.

## 1. EN

| en replaces… | Example | → |
|---|---|---|
| **du / de la / des** (some) | Tu veux **du café** ? | Oui, j'**en** veux. |
| a **quantity** (keep the number!) | J'ai **deux sœurs**. | J'**en** ai **deux**. |
| | Il achète **un kilo de** pommes. | Il **en** achète **un kilo**. |
| | Nous avons **beaucoup d'**amis. | Nous **en** avons **beaucoup**. |
| **de** + thing (verbs with *de*) | Tu parles **de ton voyage** ? | Tu **en** parles ? |
| | J'ai besoin **de farine**. | J'**en** ai besoin. |
| **de** + place (coming from) | Il revient **du marché**. | Il **en** revient. |

Negative: *Je n'ai **pas de** café.* → *Je n'**en** ai pas.* (no number after *pas*)

Verbs with **de**: parler de, avoir besoin de, avoir envie de, s'occuper de, se souvenir de, être content de, rêver de, revenir de.

## 2. Y

| y replaces… | Example | → |
|---|---|---|
| a **place** (à, au, en, dans, chez, sur…) | Je vais **au marché**. | J'**y** vais. |
| | Elle habite **en Italie**. | Elle **y** habite. |
| | Les clés sont **dans le sac**. | Les clés **y** sont. |
| **à** + thing (verbs with *à*) | Je pense **à mon voyage**. | J'**y** pense. |
| | Il joue **au tennis**. | Il **y** joue. |
| | Je réponds **à ce message**. | J'**y** réponds. |

Verbs with **à**: penser à, réfléchir à, s'intéresser à, répondre à, jouer à, participer à, s'habituer à.

## 3. ⚠ Things vs people

**y** and **en** are for **things and places**. For **people**:

| Thing | Person |
|---|---|
| Je pense **à mon pays**. → J'**y** pense. | Je pense **à ma mère**. → Je pense **à elle**. |
| Je parle **de mon travail**. → J'**en** parle. | Je parle **de mon chef**. → Je parle **de lui**. |
| Je réponds **à la lettre**. → J'**y** réponds. | Je réponds **à Paul**. → Je **lui** réponds. |

Most verbs with *à* + person use **lui / leur** (topic 01). *penser à*, *s'intéresser à* and *s'habituer à* use **à lui / à elle**.

## 4. Position: same as the other pronouns

| Structure | Example |
|---|---|
| Présent | J'**y** vais. · J'**en** veux. |
| Négation | Je **n'y** vais **pas**. · Je **n'en** veux **pas**. |
| Passé composé | J'**y** suis allé. · J'**en** ai mangé. |
| Verbe + infinitif | Je vais **y** aller. · Je veux **en** acheter. |
| Impératif + | Va**s-y** ! · Prends-**en** ! · Mange**s-en** ! |
| Impératif − | **N'y** va pas ! · **N'en** mange pas ! |

⚠ In the positive imperative, *-er* verbs and *aller* **add an s** before y / en: va → **vas-y**, mange → **manges-en**.

**Order with other pronouns:** … lui / leur → **y** → **en** (always last): *Il **y en** a.* · *Je **lui en** donne.*

## 5. Everyday expressions

| Français | English |
|---|---|
| **On y va !** | Let's go! |
| **Vas-y ! / Allez-y !** | Go ahead! |
| **Ça y est !** | That's it! / Done! |
| **Il y en a.** / **Il n'y en a plus.** | There is some. / There's none left. |
| **Je m'en vais.** | I'm leaving. |
| **J'en ai marre !** (familiar) | I'm fed up! |

## 6. Common mistakes

| ✗ | ✓ |
|---|---|
| Tu as des frères ? — Oui, j'ai deux. | Oui, j'**en** ai deux. |
| Je vais à Paris. → J'en vais. | J'**y** vais. |
| Va-y ! | **Vas-y** ! |
| Je pense à ma mère. → J'y pense. | Je pense **à elle**. |
| Il en y a. | Il **y en** a. |
| Je n'ai pas en. | Je **n'en** ai pas. |
