# 04 · Vocabulaire — Au marché et en cuisine (market and cooking)

Shops use **y** (*J'y vais*), quantities use **en** (*J'en prends un kilo*).

## Les commerces

| Français | English |
|---|---|
| le marché | the market |
| la boulangerie | the bakery |
| la boucherie | the butcher's |
| la poissonnerie | the fishmonger's |
| l'épicerie (f.) | the grocery shop |
| le supermarché | the supermarket |

## Les quantités

| Français | English | Example |
|---|---|---|
| un kilo de | a kilo of | J'en prends **un kilo**. |
| une livre de | half a kilo (500 g) | **Une livre** de cerises. |
| une bouteille de | a bottle of | |
| une douzaine de | a dozen | **Une douzaine** d'œufs. |
| une tranche de | a slice of | Deux **tranches** de jambon. |
| un morceau de | a piece of | Un **morceau** de fromage. |
| un paquet de | a packet of | |
| une boîte de | a tin / box of | |
| un peu de · assez de · trop de | a little · enough · too much | J'en ai **assez**. |

## En cuisine

| Français | English | Example |
|---|---|---|
| faire les courses | to do the shopping | |
| la farine | flour | |
| le beurre | butter | |
| le jambon | ham | |
| un œuf / des œufs | an egg / eggs | |
| goûter | to taste | Tu veux **goûter** ? |
| il reste… | there is … left | Il **reste** du lait ? |
| il manque… | … is missing | Il **manque** du sel. |

## Expressions with y and en

| Français | English |
|---|---|
| On y va ! | Let's go! |
| Vas-y ! / Allez-y ! | Go ahead! |
| Ça y est ! | That's it! / Done! |
| Il y en a. / Il n'y en a plus. | There is some. / There's none left. |
| Je m'en vais. | I'm leaving. |
| J'en ai marre ! (familiar) | I'm fed up! |
