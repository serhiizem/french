# 03 · Vocabulaire — La météo et les sorties (weather and going out)

Perfect words for *S'il pleut, on…*

## La météo

| Français | English | Example |
|---|---|---|
| la météo | the weather forecast | Je regarde la **météo**. |
| les prévisions (f.) | the forecast | Les **prévisions** sont bonnes. |
| il fait beau / mauvais | the weather is nice / bad | S'il **fait beau**, on sort. |
| il pleut (pleuvoir) | it's raining | S'il **pleut**, je reste. |
| il neige | it's snowing | S'il **neige**, on fera du ski. |
| il y a du vent | it's windy | |
| un orage | a storm | |
| un parapluie | an umbrella | Prends ton **parapluie** ! |
| mouillé(e) | wet | Tu seras **mouillé**. |

## Les sorties

| Français | English | Example |
|---|---|---|
| faire une randonnée | to go hiking | On **fera une randonnée** dimanche. |
| un pique-nique | a picnic | |
| annuler | to cancel | On **annulera** le pique-nique. |
| reporter | to postpone | On peut **reporter** à samedi. |
| rater (le train) | to miss (the train) | Tu vas **rater** le train ! |
| être en retard | to be late | |
| prévenir qqn | to let someone know (like *venir*) | **Préviens**-moi ! |
| emporter | to take along | **Emporte** un pull. |
| s'habiller chaudement | to dress warmly | |
| attraper un rhume | to catch a cold | |
