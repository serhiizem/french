# 03 · Les phrases avec si : si + présent

> **S'il pleut demain, je prendrai le bus.** = If it rains tomorrow, I'll take the bus.
> French name: *l'hypothèse réelle* (the condition is possible or true).
> English: zero and first conditional.

## 1. Three combinations

| si + … | then … | Meaning | Example |
|---|---|---|---|
| présent | **présent** | habit, general truth (= every time) | S'il **pleut**, je **prends** le bus. |
| présent | **futur** | real possibility in the future | S'il **pleut** demain, je **prendrai** le bus. |
| présent | **impératif** | instruction, advice | S'il **pleut**, **prends** ton parapluie ! |

The futur proche also works for the future: *Si tu cours, tu **vas tomber**.*

## 2. ⚠ The golden rule

**Never the futur right after *si*.** English does the same: *if it rains*, not *if it will rain*.

- ~~S'il pleuvra demain…~~ → S'il **pleut** demain…
- ~~Si j'aurai le temps…~~ → Si j'**ai** le temps…

## 3. Order and comma

The *si* part can come first or second:

- **Si tu as faim,** mange une pomme. (comma)
- Mange une pomme **si tu as faim.** (no comma)

## 4. Elision: s'il

**si + il / ils → s'il / s'ils**, and only those two.

| ✓ elision | ✓ no elision |
|---|---|
| **s'il** pleut | **si elle** vient |
| **s'ils** arrivent | **si on** part |
| | **si elles** veulent |

## 5. The full picture of *si* sentences

| Type | si + … | main verb | Example |
|---|---|---|---|
| **Réel** (this topic) | présent | présent / futur / impératif | Si j'ai le temps, je **viendrai**. |
| **Irréel du présent** (topic 02) | imparfait | conditionnel | Si j'avais le temps, je **viendrais**. |
| Irréel du passé (later) | plus-que-parfait | conditionnel passé | Si j'avais eu le temps, je **serais venu**. |

*Si j'ai le temps* means it's possible. *Si j'avais le temps* means I probably don't have time; I'm imagining.

## 6. Common mistakes

| ✗ | ✓ |
|---|---|
| S'il fera beau, on ira à la plage. | S'il **fait** beau, on ira à la plage. |
| Si il pleut… | **S'il** pleut… |
| S'elle vient… | **Si elle** vient… |
| Si j'aurai le temps, je t'appellerai. | Si j'**ai** le temps, je t'appellerai. |
| Si vous venez, vous verriez la mer. | Si vous venez, vous **verrez** la mer. |
