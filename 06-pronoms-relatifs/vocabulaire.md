# 06 · Vocabulaire — Mon quartier et mon logement

Perfect for *le quartier **où** j'habite*, *l'appartement **que** je loue*, *le voisin **dont** je parle*.

## Le logement

| Français | English | Example |
|---|---|---|
| un immeuble | a block of flats | |
| un étage | a floor | J'habite au 3e **étage**. |
| un ascenseur | a lift, elevator | |
| louer | to rent | L'appartement **que** je **loue**. |
| le loyer | the rent | Le **loyer** est trop cher. |
| le / la propriétaire | the landlord / owner | |
| le / la locataire | the tenant | |
| un(e) colocataire | a flatmate | |

## Le quartier

| Français | English |
|---|---|
| le quartier | the neighbourhood |
| le centre-ville | the town centre |
| la banlieue | the suburbs |
| une rue piétonne | a pedestrian street |
| une place | a square |
| la mairie | the town hall |
| animé(e) | lively |
| calme | quiet |

## Verbs with *de* (→ dont)

| Français | English | Example |
|---|---|---|
| parler de | to talk about | Le film **dont** je parle. |
| avoir besoin de | to need | Ce **dont** j'ai besoin. |
| avoir peur de | to be afraid of | Le chien **dont** j'ai peur. |
| se souvenir de | to remember | Un jour **dont** je me souviens. |
| rêver de | to dream of | La ville **dont** je rêve. |
| s'occuper de | to take care of | Les enfants **dont** elle s'occupe. |
| se servir de | to use | L'outil **dont** je me sers. |
| être fier / fière de | to be proud of | Un projet **dont** je suis fier. |
