# 02 · Le conditionnel présent

> **Si j'étais riche, je voyagerais.** = If I were rich, I would travel.
> The conditionnel = English **would** + verb.

## 1. Formation

**Futur stem + imparfait endings.**
Regular verbs: the stem is the infinitive (verbs in **-re** drop the final *e*).

| | parler | finir | prendre |
|---|---|---|---|
| je | parler**ais** | finir**ais** | prendr**ais** |
| tu | parler**ais** | finir**ais** | prendr**ais** |
| il / elle / on | parler**ait** | finir**ait** | prendr**ait** |
| nous | parler**ions** | finir**ions** | prendr**ions** |
| vous | parler**iez** | finir**iez** | prendr**iez** |
| ils / elles | parler**aient** | finir**aient** | prendr**aient** |

The endings are exactly the imparfait endings: *-ais, -ais, -ait, -ions, -iez, -aient*.
The **r** before them is the sign of the conditionnel (and of the futur).

## 2. Irregular stems (same as the futur)

| infinitif | stem | je… |
|---|---|---|
| être | ser- | je serais |
| avoir | aur- | j'aurais |
| aller | ir- | j'irais |
| faire | fer- | je ferais |
| pouvoir | pourr- | je pourrais |
| vouloir | voudr- | je voudrais |
| devoir | devr- | je devrais |
| savoir | saur- | je saurais |
| venir | viendr- | je viendrais |
| voir | verr- | je verrais |
| envoyer | enverr- | j'enverrais |
| recevoir | recevr- | je recevrais |
| falloir | faudr- | il faudrait |
| valoir | vaudr- | il vaudrait mieux |

Spelling changes, as in the futur: acheter → j'**achè**terais · appeler → j'**appell**erais · payer → je **pai**erais.

## 3. When do we use it?

| Use | Example |
|---|---|
| **Politeness** | Je **voudrais** un café. · **Pourriez**-vous m'aider ? |
| **Wish** | J'**aimerais** visiter le Japon. · Ce **serait** génial ! |
| **Advice** | Tu **devrais** dormir plus. · À ta place, je **prendrais** le train. · Il **vaudrait** mieux partir. |
| **Hypothesis** | Si j'**avais** le temps, je **lirais** plus. |
| Unconfirmed news (bonus) | Le ministre **serait** malade. (= reportedly) |

## 4. ⚠ The golden rule with *si*

**si + imparfait → conditionnel**

- Si j'**avais** de l'argent, j'**achèterais** une maison.
- J'**achèterais** une maison si j'**avais** de l'argent. (the order can switch)

**Never use the conditionnel right after *si*:** ~~Si j'aurais~~ → Si j'**avais**.

Compare with a real possibility: **si + présent → futur**
*S'il **fait** beau demain, nous **irons** à la plage.*

## 5. Futur or conditionnel?

| futur (will) | conditionnel (would) |
|---|---|
| je parler**ai** | je parler**ais** |
| tu parler**as** | tu parler**ais** |
| il parler**a** | il parler**ait** |
| nous parler**ons** | nous parler**ions** |
| vous parler**ez** | vous parler**iez** |
| ils parler**ont** | ils parler**aient** |

With **je**, the two sound almost the same (*-rai* [ré] / *-rais* [rè]), so check the spelling.
*Je voudrai* = I will want ✗ in a café · *Je voudr**ais*** = I would like ✓

## 6. Common mistakes

| ✗ | ✓ |
|---|---|
| Si j'aurais le temps… | Si j'**avais** le temps… |
| Je voudrai un café, s'il vous plaît. | Je **voudrais** un café… |
| Tu pouvrais m'aider ? | Tu **pourrais** m'aider ? |
| Nous prendrerions le bus. | Nous **prendrions** le bus. |
| Je serai content si tu venais. | Je **serais** content si tu venais. |
