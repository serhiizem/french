# 01 · L'ordre des pronoms compléments

> **Je le lui donne.** = I give it to him/her.

## 1. The order (before the verb)

```
me / te / se / nous / vous  →  le / la / l' / les  →  lui / leur  →  y  →  en  →  VERBE
```

| Example | Pattern |
|---|---|
| Il **me le** donne. | me + le |
| Je **te la** prête. | te + la |
| Elle **nous les** montre. | nous + les |
| Je **le lui** donne. | le + lui |
| Nous **la leur** envoyons. | la + leur |
| Je **lui en** donne. | lui + en |

**Memory trick (3rd person):** sort them alphabetically. **la, le, les** come before **leur, lui** (*e* before *u*).
**Other persons:** me / te / nous / vous go **first**: *Il **me le** dit.*

## 2. Where they go

| Tense / structure | Rule | Example |
|---|---|---|
| Présent | before the verb | Je **le lui** donne. |
| Négation | `ne` + pronouns + verb + `pas` | Je **ne le lui** donne **pas**. |
| Passé composé | before the **auxiliary** (avoir/être) | Je **le lui ai** donné. |
| Verbe + infinitif | before the **infinitive** | Je vais **le lui donner**. |
| Impératif ✅ | after the verb, with hyphens, COD first | Donne-**le-lui** ! Donne-**le-moi** ! |
| Impératif ❌ | normal order | **Ne le lui** donne **pas** ! |

In the positive imperative, `me` → `moi` and `te` → `toi`: *Donne-le-**moi** !*

## 3. ⚠ Passé composé: agreement

When **le / la / les** (a direct object) comes **before avoir**, the past participle agrees with it:

- J'ai donné **la clé** à Paul. → Je **la** lui ai donné**e**.
- J'ai rendu **les livres** à Marie. → Je **les** lui ai rendu**s**.
- J'ai rendu **les clés** à Marie. → Je **les** lui ai rendu**es**.

The participle **never** agrees with `lui` / `leur`. They are indirect objects.

## 4. Elision

`me, te, le, la` → `m', t', l'` before a vowel or a silent *h*:

- Je **te l'**ai dit. · Il **me l'**a prêté. · Elle **nous l'**apporte.
- `lui` **never** elides: Je **le lui** ai dit. (not *l'lui*)

## 5. Bonus: `en` always comes last

- Je **lui en** donne. (des bonbons)
- Il **m'en** reste. (du pain)
- Donne-**m'en** ! (du café)

## 6. Common mistakes

| ✗ | ✓ |
|---|---|
| Je ~~lui le~~ donne. | Je **le lui** donne. |
| Donne-~~moi-le~~ ! | Donne-**le-moi** ! |
| Je ~~l'ai lui~~ donné. | Je **le lui ai** donné. |
| Je ne ~~lui le donne~~ pas. | Je **ne le lui** donne **pas**. |
| Je vais ~~le lui~~ vais donner. | Je vais **le lui donner**. |
